# Qwen3-ASR Batch Audio Transcription Tool

基于 [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) 的批量音频转文字工具，提供图形化操作界面。

A GUI-based batch audio transcription tool powered by [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR).

---

## Features / 功能特性

- 使用 NVIDIA GPU 加速推理NVIDIA GPU acceleration
- 支持 Qwen3-ASR-1.7B 和 Qwen3-ASR-0.6BSupport for Qwen3-ASR-1.7B and Qwen3-ASR-0.6B
- 批量处理文件夹中的音频文件Batch process audio files in a selected folder
- 输出与音频文件同名的 `.txt` 文件Generate `.txt` files with the same names as the input audio files
- 自定义输入文件夹和输出文件夹Select input and output directories
- 已存在同名 TXT 文件时逐个提示覆盖或跳过Prompt individually to overwrite or skip existing TXT files
- 流式显示当前识别结果Display transcription results in real time
- 显示当前文件字数和 Chunk 进度Show character count and Chunk progress
- 显示当前文件和整个任务的预计剩余时间Display estimated remaining time for the current file and the entire task
- 显示 GPU 显存使用、总占用和剩余显存Display GPU memory usage, total usage, and available memory
- 自动记忆上次使用的路径和参数Remember previously used paths and parameters
- 使用后台线程执行识别，避免界面卡死
  Run transcription in a background thread to keep the GUI responsive

## Project Structure / 项目结构

```text
qwen3-asr/
├── asr_front.py          # 图形化前端 / GUI frontend
├── qsr_server.py          # ASR 识别核心代码 / ASR backend
├── README.md
└── models/
    ├── Qwen3-ASR-1.7B/
    └── Qwen3-ASR-0.6B/
```

模型目录也可以保存在项目目录之外，例如：

```text
D:/models/Qwen3-ASR-1.7B
/home/user/models/Qwen3-ASR-1.7B
```

## Requirements / 环境要求

- Python 3.12
- Conda 或 Miniconda
- NVIDIA GPU（推荐）
- 已正确安装 NVIDIA 驱动
- 与 PyTorch 兼容的 CUDA 驱动环境

Supported audio formats / 支持的音频格式：

```text
.wav
.mp3
.m4a
.flac
.ogg
.aac
.wma
```

没有 NVIDIA GPU 时也可以使用 CPU，但推理速度会明显降低。

The application can also run on CPU, but transcription will be significantly slower.

## Environment Setup / 环境配置

### Create the Conda environment / 创建 Conda 环境

```bash
conda create -n qwen3-asr python=3.12 -y
conda activate qwen3-asr
```

### Check the NVIDIA driver / 检查 NVIDIA 驱动

```bash
nvidia-smi
```

输出中通常会包含：

```text
Driver Version: 535.xx.xx
CUDA Version: 12.x
```

`nvidia-smi` 中显示的 `CUDA Version` 表示当前 NVIDIA 驱动支持的最高 CUDA 版本。它不一定等于本地安装的 CUDA Toolkit 版本。

The CUDA version displayed by `nvidia-smi` indicates the highest CUDA version supported by the installed NVIDIA driver. It may not be the same as the locally installed CUDA Toolkit version.

### Install PyTorch / 安装 PyTorch

请根据你的操作系统、Python 版本和 CUDA 环境，前往 PyTorch 官网获取安装命令：

Visit the official PyTorch website to select the appropriate installation command:

[https://pytorch.org/get-started/locally/](https://pytorch.org/get-started/locally/)

选择：

- Stable
- 对应的操作系统 / Operating System
- Pip
- Python
- 与 NVIDIA 驱动兼容的 CUDA 版本 / Compatible CUDA version

例如，PyTorch 官网可能生成如下命令：

```bash
pip install torch torchvision torchaudio \
    --index-url https://download.pytorch.org/whl/cu124
```

或者：

```bash
pip install torch torchvision torchaudio \
    --index-url https://download.pytorch.org/whl/cu118
```

请以 PyTorch 官网当前生成的命令为准。

Use the command generated by the PyTorch website rather than copying an outdated CUDA installation command.

### Install project dependencies / 安装项目依赖

```bash
pip install -U qwen-asr modelscope numpy librosa tqdm
```

如果 Linux 系统缺少 Tkinter，请安装：

```bash
sudo apt install python3-tk
```

Windows 通常会随 Python 一起安装 Tkinter。如果系统中没有 Tkinter，请重新安装 Python，并确保勾选 Tcl/Tk 组件。

On Windows, Tkinter is usually included with Python. If it is unavailable, reinstall Python with the Tcl/Tk component enabled.

### Download the models / 下载模型

选择一个目录用于保存模型：

```bash
cd /path/to/your/models
```

Linux 示例：

```bash
mkdir -p ~/models
cd ~/models
```

Windows PowerShell 示例：

```powershell
mkdir D:\models
cd D:\models
```

下载 Qwen3-ASR-1.7B：

```bash
modelscope download \
    --model Qwen/Qwen3-ASR-1.7B \
    --local_dir ./Qwen3-ASR-1.7B
```

下载 Qwen3-ASR-0.6B：

```bash
modelscope download \
    --model Qwen/Qwen3-ASR-0.6B \
    --local_dir ./Qwen3-ASR-0.6B
```

## Quick Start / 快速开始

```bash
# 创建并激活环境
conda create -n qwen3-asr python=3.12 -y
conda activate qwen3-asr

# 按照 PyTorch 官网安装对应 CUDA 版本的 PyTorch
# https://pytorch.org/get-started/locally/

# 安装项目依赖
pip install -U qwen-asr modelscope numpy librosa tqdm

# 验证 GPU
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"

# 下载模型
modelscope download \
    --model Qwen/Qwen3-ASR-1.7B \
    --local_dir ./Qwen3-ASR-1.7B

# 启动图形化前端
python asr_front.py
```

启动后选择输入文件夹、输出文件夹和模型目录，即可开始批量音频转文字。

## Run and Usage / 运行与使用

### Start the application / 启动程序

进入项目目录：

```bash
cd /path/to/qwen3-asr
```

激活 Conda 环境：

```bash
conda activate qwen3-asr
```

启动图形化前端：

```bash
python asr_front.py
```

### Configure the application / 配置程序

启动后，在界面中选择：

1. **输入文件夹 / Input Directory**

   选择需要转换的音频文件目录。
2. **输出文件夹 / Output Directory**

   选择 TXT 文件保存目录。
3. **模型目录 / Model Directory**

   选择已经下载的模型目录，例如：

   ```text
   Qwen3-ASR-1.7B
   ```
4. **识别参数 / Transcription Parameters**

   可以配置：

   - 运行设备 / Device：`cuda` 或 `cpu`
   - 数据类型 / Dtype：`float16`、`float32` 或 `bfloat16`
   - 语言 / Language
   - Chunk 长度 / Chunk size
   - Chunk 重叠长度 / Chunk overlap
   - 最大生成 Token 数 / Maximum new tokens

完成配置后，点击：

```text
开始批量转换
Start Batch Conversion
```

程序会按照文件名排序，并逐个处理输入文件夹中的音频文件。

The application sorts audio files by filename and processes them one by one.

### Output files / 输出文件

例如输入目录为：

```text
audio/
├── meeting_001.wav
├── meeting_002.mp3
└── meeting_003.flac
```

输出目录为：

```text
text/
```

转换后会生成：

```text
text/
├── meeting_001.txt
├── meeting_002.txt
└── meeting_003.txt
```

文件名只替换扩展名：

```text
meeting_001.wav  -> meeting_001.txt
meeting_002.mp3  -> meeting_002.txt
meeting_003.flac -> meeting_003.txt
```

### Existing TXT files / 已存在的 TXT 文件

如果输出目录中已经存在同名 TXT 文件，程序会逐个弹出确认窗口：

```text
文件 meeting_001.txt 已经存在。

是否覆盖？
```

选择：

- **是 / Yes**：覆盖当前 TXT 文件
- **否 / No**：跳过当前音频文件

当前处理策略是逐个询问，以避免误覆盖已有结果。

The application asks separately for each existing TXT file to prevent accidental overwriting.

### Real-time status / 实时状态显示

转换过程中，界面会显示：

```text
文件进度：3/20
Chunk：5/18
当前文件字数：1256
当前文件预计剩余：00:02:35
全部任务预计剩余：00:18:42
```

显示内容包括：

- 当前文件进度；
- 当前文件的 Chunk 进度；
- 已生成文本的字数；
- 当前文件预计剩余时间；
- 整个批量任务预计剩余时间；
- 当前正在转换的文件名；
- 实时识别结果。

The GUI displays file progress, Chunk progress, character count, current transcription output, and estimated remaining time.

### GPU memory monitoring / GPU 显存监控

使用 CUDA 时，界面会显示类似：

```text
NVIDIA GeForce RTX 3090 |
进程使用: 3.21 GiB |
缓存: 4.02 GiB |
GPU占用: 8.15 GiB / 24.00 GiB |
剩余: 15.85 GiB
```

各字段含义：

| 字段                     | 说明                                   |
| ------------------------ | -------------------------------------- |
| 进程使用 / Process Usage | 当前 Python/PyTorch 进程实际分配的显存 |
| 缓存 / Reserved          | PyTorch 预留的缓存显存                 |
| GPU 占用 / GPU Usage     | 整张显卡当前已使用的显存               |
| 总显存 / Total           | GPU 的总显存                           |
| 剩余 / Free              | GPU 当前可用的显存                     |

如果显示：

```text
GPU 不可用 / GPU unavailable
```

说明当前程序可能运行在 CPU 上，或者 PyTorch 没有正确识别 CUDA。

### Configuration persistence / 配置记忆

程序会自动保存上次使用的配置，包括：

- 输入文件夹；
- 输出文件夹；
- 模型目录；
- 设备；
- 数据类型；
- 语言；
- Chunk 参数；
- 最大 Token 数；
- 音频扩展名设置。

配置文件默认保存在：

```text
~/.qsr_transcriber_config.json
```

下次启动程序时会自动恢复这些设置。

The application automatically stores the previous paths and recognition parameters and restores them on the next launch.
